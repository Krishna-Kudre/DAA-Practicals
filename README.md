**Practical 1. Implementation and Time Analysis of Sorting Algorithms**

Summary:
The sorting algorithms (Bubble, Selection, Insertion, Merge, and Quick Sort) were implemented and tested. Their execution times were compared to understand their efficiency for different input sizes.

Conclusion:
Merge Sort and Quick Sort are faster and more efficient for large datasets, while Bubble, Selection, and Insertion Sort are simple and suitable for small datasets or learning purposes.

**Practical 2. Implementation and Time Analysis of Linear and Binary Search Algorithms**

Summary:
Linear Search and Binary Search were implemented and their execution times were analyzed. Linear Search checks elements one by one, while Binary Search works on sorted data by repeatedly dividing the search range.

Conclusion:
Binary Search is much faster than Linear Search for sorted data. Linear Search is easy to use but slower for large datasets.
